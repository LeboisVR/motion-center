> La base d'app STM32 est auto-détectée par `_stm32_infer_app_base` via le reset vector du `.bin` (bases connues : `0x08040000` G4/G474, `0x08005000` F103). **PRO V2.3 (G431) : app à `0x08000000`, mise à jour par le bootloader SYSTÈME DFU en ROM** (BOOT0=1 au reset ou commande `!DFU` → saut `0x1FFF0000`), flashée par STM32CubeProgrammer / dfu-util — elle **n'utilise pas** le flasheur CDC de Motion Center. Le G431 est **mono-banque** (128 Ko, pages 2 Ko) : pas d'option byte DBANK.

## Protocole série commun (firmware ≥ 2.1)

| Direction | Commande / Réponse |
|-----------|-------------------|
| → | `HELLO` |
| ← | `OK_MC_CONNECTED` |
| → | `GET` |
| ← | `STATUS FW=x.y.z BOX=n SERVO=0\|1 HSPS=nnn ESTOP=0\|1 ESTOPB=0\|1\|2 MCMIN=x.y M1=conn,cal,max,margin,hdir,endpark ...` |
| → | `ENABLE` / `DISABLE` / `MC_DISABLE` / `DISCONNECT` |
| → | `DO SERVO_ON\|SERVO_OFF\|FULL_CALIB <n>\|DETECT_MIN <n>` |
| → | `SET HOMING_S <n>` / `SET ESTOP 0\|1` / `SET CONNECTED <m> 0\|1` / `SET MAX <m> <v>` / `SET MARGIN <m> <v>` / `SET HOMING_DIR <0\|1> <m>` / `SET ENDPARK <pct> <m>` |

> **Convention MAX (M1..M4)** : unités 15 bits, défaut usine **32767** sur toutes les box (clamp firmware + app). Sur AVR, la conversion en pas physiques (×2, course ≈65535 pas) se fait dans le mapping firmware ; sur F103/G431/G4 c'est 1:1 (course 32767 pas).
> Le mapping consigne→cible est centralisé dans `firmware hardware/shared/PosMap.h` (`PosMap_TargetBase` M1..M4 avec `stepScale`, `PosMap_TargetOptional` M5/M6 avec course utile `max − 2×margin`) — consommé par l'AVR et le F103. Sur **G431 (V2.3)**, les 6 moteurs passent par `PosMap_TargetOptional` (tous homés/calibrables).
> Le format de la trame `P` (tag, 7 axes, 15 octets, décodage BE 15 bits) est défini dans `firmware hardware/shared/PFrame.h` (`PFRAME_TAG/AXES/LEN`, `PFrame_Axis`) — consommé par les 4 firmwares (AVR, F103, G431, G4).
> **Direction de homing** : `SET HOMING_DIR <0|1> <m>` (0=MIN défaut, 1=MAX) + 5ᵉ champ STATUS `Mx=conn,cal,max,margin,hdir`. Sémantique commune dans `firmware hardware/shared/HomingDir.h` : homing MAX exige un max calibré (sinon repli MIN) ; position posée après homing = 0 (MIN) ou `max−2×margin` (MAX, AVR/F103) / `max` (G4, marge gérée au mapping). AVR/F103 : M5/M6, persisté (EEPROM/NVM offsets 76/80) ; **G431 (V2.3) : M1..M6, persisté (NVM offsets 60..70)** ; G4 : tous moteurs, RAM (NVM non portée). L'app : clic sur la colonne « Dir homing » de l'onglet Status.
> **Endpark** : `SET ENDPARK <pct> <m>` (0..100 = % de la course utile `max−2×margin`, **255 = off**, défaut) + 6ᵉ champ STATUS `Mx=conn,cal,max,margin,hdir,endpark`. Au `SH_DISABLE`, les vérins éligibles (AVR/F103 : M5/M6 connectés+homés+calibrés ; **G431 : M1..M6 connectés+homés+calibrés** ; G4 : M5..M7 connectés) rejoignent **doucement** (vitesse de homing) `pct%` de la course, PUIS la procédure d'arrêt existante s'exécute (servo off + `SH_DISABLED`). Bloquant côté firmware (filet timeout calculé + abort `!`/ESTOP). Persisté EEPROM/NVM offsets 84/88 (AVR/F103) / **72..82 (G431)** (cellule vierge ⇒ off), RAM sur G4. L'app : clic sur la colonne « Endpark » de l'onglet Status (slider % + case désactiver).
| → | `STEP <m> <steps>` |
| → | `!DFU` |
| ← | `DFU\n` puis reset dans le bootloader |

Baud fixe : **115 200**. `REQUIRED_BOX_FIRMWARE_PREFIX` côté MC = `"2.1"`.
